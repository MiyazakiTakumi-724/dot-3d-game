# Sprite Stack Action（鉄球の試作）

sprite stackingで描いた見下ろしアクションの試作。鉄球だけで敵を全滅させるとクリア。

## 遊び方
1. Godot 4.5 以降をインストールし、このフォルダの `project.godot` を開く。
2. F5 で実行。

| 操作 | キー |
|---|---|
| 移動（画面基準） | 矢印キー / WASD |
| カメラを回す | マウスのボタン（左右どちらでも）を押したまま左右に動かす / Q・E |
| 鉄球を目の前に落とす | X |
| 鉄球を拾う（同じマスに立って） | Z |
| やり直し（クリア / ゲームオーバー後） | R |

- 段差は近づくと自動で登る。登れるのは1段まで、飛び降りは3段まで。
- 鉄球のダメージ = 落ちた段数 + 1。敵の体力は3なので、3段上から落とせば一撃。
- 灰色の壁の陰に入ると敵の弾を防げる。

## テスト
```
./run_tests.sh            # 全部
./run_tests.sh test_iron_ball.gd
```
GUT 9.5.0 を `addons/gut` に同梱。

## Windows 向け書き出し
エディタの「プロジェクト → エクスポート」で、エクスポートテンプレートを入れてから「Windows Desktop」を書き出す（`build/windows/` に出力）。
