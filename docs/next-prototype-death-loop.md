# 次の試作：死と取り返しの流れ（引き継ぎ用ブリーフ）

ステータス：**設計済み・実装済み（2026-11-24）。** 設計は `docs/superpowers/specs/2026-11-23-death-loop-design.md`。下の「まだ確認していない点」はすべてユーザーに確認済みで、答えは設計メモにある。

## この試作で確かめること

死ぬ → チェックポイントから再開 → 墓石を取り返しに行く、という流れが「緊張感」になるか「面倒」になるか。これがこのゲームの手触りの核なので、先に確かめる。

## 入れるもの（docs/design.md の 9・10・11 章が根拠）

- チェックポイント：休憩所と分かる見た目にする。ここで再開する。
- 墓石：
  - 死んだ場所に置かれ、持ち物をすべて入れる。
  - 世界に1つだけ。新しく死ぬと古い墓石は中身ごと消える。
  - お金は半分が墓石に入り、半分は手元に残る。経験値は手元に残る。
- 武器のランク：死んでも各武器の最低ランクは手元に残る。
- ショートカット：エリアの奥で開けると、チェックポイント近くへ戻れる扉かはしご。
- 拾えるもの：お金、素材、高ランクの鉄球（試作用に1つ）。
- 試作1のエリアを広げるか、新しいエリアを作る。チェックポイントから墓石まで、ある程度の距離が要る。

## ユーザーにまだ確認していない点

ここは推測で決めずに、ユーザーに聞くこと。

1. 試作用の「高ランクの鉄球」は、何が違うか。ダメージ、落とせる範囲など。
2. 墓石を取り返す操作。近づくだけで拾うか、攻撃して壊すか（Core Keeperは叩いて壊す）。
3. 体力の回復手段。チェックポイントで全回復するか、回復アイテムを置くか。
4. 死んだときの敵の扱い。倒した敵は復活するか。
5. 落下死や、ステージ外での死は起こりうるか。起こるなら、design.md の【提案】どおり墓石を置き直すか。
6. 簡単モードで、この流れのどこを緩めるか。この試作の範囲外にしてよいか。
