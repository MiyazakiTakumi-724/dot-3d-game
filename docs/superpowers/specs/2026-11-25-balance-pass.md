# 遊んでみての直し（敵・ボス・画面・エリア・バランス）設計

日付：2026-11-25（夜）
前提：`2026-11-25-full-game-design.md`。食い違う所はこちらが優先。

ユーザーの依頼（2026-11-25 17:28、原文）：

> 敵が弱すぎるからステータス基準値あげて / 工夫しないと倒せない / 全ての敵の動き単純すぎ（特にボス） /
> 敵キャラもグラフィックちゃんとして / 敵の種類増やして / 浮いてる敵には剣と鉄球当たらないようにして /
> 他にもゲームバランス調整すべきとこ探して修正 / エリア一つにつきもっと区分増やして /
> もっとたくさん探索してボスを倒す形にしたい / 隠しボスエリア一つにつき一体配置 / 杖のクールタイムが分かりにくい /
> マナといのちはバーで表示 / ボスから入手できるのはランク4装備ではなくランク4装備の素材とする
> （倒してもすぐ装備作れず主人公が相応に強くなってから使える） / ボスの仕様がちゃんと反映されているかテストしたうえで確認して /
> アイテムすべてにアイコンをつけて一覧表示する / 詳細はカーソルを合わせると表示される /
> 武器全種類所持してると上の文字つぶされて5のアイテム今何持ってるか見えなくなる / もっと分かりやすくする

細かい所は【Claudeの判断】で決めた（数値はすべて【提案】）。

## 1. 画面

- 左上：いのちのバー（赤）とマナのバー（青）。バーの右に数（例 18/20）。その下に細い経験値のバーと「Lv」「お金」。
- 下の真ん中：手に持つ物の欄を5つの箱にする（アイコンと番号。持っていない武器は暗い箱）。選んでいる箱は明るい枠。
  選んでいる物の名前は箱の上に1行で出す。弓は箱の右下に矢の数、道具は数。
- 杖：箱の上に、使える魔法を小さなアイコンで並べ（選んでいるものは枠）、待ち時間の間はアイコンが下から暗くなり、残り秒を出す。
  マナが足りない魔法は赤い印。
- 操作の説明は、はじめの30秒だけ出す。

## 2. アイコンと持ち物の一覧

- すべての品物（装備・素材・道具・矢・お金）に16×16のドット絵のアイコンを、コードで作る（`ItemIcons`）。
  装備は枠ごとの形（鉄球・剣・弓・杖・服）にランクの色の縁。素材・道具・矢も種類ごとの形と色。
- 持ち物のページ：アイコンを格子に並べ、右下に数。カーソルを合わせると、名前・ランク・特色・装備できるレベル・説明が出る。
  装備のページで品物を選ぶ所と、お店の画面もアイコン付きにし、カーソルで詳しく出す。

## 3. ボスの落とし物と、強くなってから使う

- ボスはランク4の装備を落とさない。落とすのは「ボスの素材」（2つ）と経験値とお金。ランク4の装備は鍛冶屋で、ボスの素材と地方の素材で作る。
- 装備にはランクごとに「使えるレベル」：ランク1・2はいつでも、ランク3は Lv6、ランク4は Lv12、ランク5は Lv18。
  レベルが足りない品物は、持てるが装備できない（一覧で赤く「Lv12から」と出る）。

## 4. 敵

- 基準の数値を上げる：体力はおよそ3倍、攻撃力はおよそ1.6倍。経験値も合わせて上げる。主人公も最大いのち20（1ポイント＋3）にする。
- 浮いている敵（コウモリ・蜂）には剣と鉄球が当たらない（弓・魔法・爆弾で倒す）。
- 動きを賢くする（ためは光って分かる）：
  - スライム：近づくと、ためてから跳びかかる。
  - ゴブリン：寄って、ためて叩き、少し下がる（当て逃げ）。
  - 射手：近づかれると離れる。3発続けて撃つことがある。
  - 盾持ち：いつも主人公の方へ向き直る（回りこむのは遅いので、上から鉄球か背中から）。
  - 影：近づくと、ためてから速く跳びこむ。
  - コウモリ：ふらふら回り、ときどき狙って急降下し、また離れる。
  - イノシシ：突進して壁にぶつかると、しばらく目を回す（そのとき受けるダメージ×2）。
  - 火の玉：今のまま（寄って弾ける）。
  - 亡霊：すけたり（攻撃がすり抜ける）見えたりをくり返す。
- 新しい敵（6種）：
  - 槍兵：少し離れて構え、ためてから長く突く。廃城・山岳。
  - 投石兵：主人公のいる所へ石を山なりに投げる（落ちる所に影。壁を越える）。近づかれると逃げる。山岳・草原。
  - 魔術師：ときどき別の場所へ消えて現れ、3方向に遅い弾を撃つ（作るときに、追いかける玉より、よけ方が分かる扇にした）。廃城・塔。
  - 甲虫：かたい殻で剣・矢・魔法は1しか入らない。鉄球か爆弾を当てるとひっくり返り（3秒）、その間はふつうに入る。草原・溶岩。
  - 蜂：浮いている小さな敵。速く、2〜3匹で出る。草原・山岳。
  - 擬態箱：宝箱のふりをしていて、近づくか攻撃されると目を覚まして噛みつく。倒すとお金4倍・素材2つ・40%で装備。廃城・溶岩。

## 5. ボス（どれも体力が半分を切ると2段目になり、攻撃が増える・速くなる）

| ボス | 1段目 | 2段目で足す |
|---|---|---|
| 岩転がしの巨人 | 岩棚から岩を投げる（3つに分かれることも）。同じ高さで踏みつけ | 下の地面の端から端へ大岩を転がす（横によける） |
| 草むらの大蛇 | カメラの向きが合うときだけ見える。噛みつき、尾で払う（まわり） | 地面にもぐって主人公の足元から出る（影が先に出る）、毒の息 |
| 満ち引きする溶岩 | 満ち引き、引いたとき火を吐く（3方向） | 満ち引きが速くなる。地面から火柱（先に印） |
| 廃城の主 | 足音で追う。横に広く斬る | まっすぐ突進して斬る。亡霊を2体呼ぶ |
| 岩窟のぬし | ゆっくり寄って叩く、まわりに岩を落とす | 丸まって転がり、壁にぶつかると目を回す（そのとき×2） |
| 溶岩洞のぬし | 走り回り、跡が燃える | 跳びかかり、着地でまわりに炎の輪 |
| 双子 | 片方が後ろに隠れる。叩く・撃つ | 入れ替わる。片方が倒れると、残りが怒って速くなる |
| らせん塔の番人 | 回って、正面に立つと撃つ。背中だけ効く | 回る向きが変わる。まわりを薙ぐ回転攻撃 |
| ブライト | 背中の目が光をためて画面を白くする。背中だけ効く | 光の雨（落ちる所に印）、影を呼ぶ |
| 女王蜂（新・草原の隠し） | 浮いている（剣・鉄球は当たらない）。針を撃つ、蜂を呼ぶ | 急降下 |
| 宝箱の王（新・廃城の隠し） | にせものの宝箱4つにまぎれ、本物だけが噛みつく。本物は背中に金のしっぽ（カメラを回すと見える）。にせものは1回で壊れる | 宝箱が速く入れ替わる（6秒→3.5秒） |

- 落とし物：ボスの素材2つ（女王蜂は「女王の針」、宝箱の王は「王の宝冠」）。
- ボスの体力のバーには半分の所に印があり、2段目になると名前に「（怒り）」が付く。
- 呼んだ手下（亡霊・蜂・影）は3体まで。倒しても落とし物も経験値もない。
- 仕様は `tests/test_bosses.gd` で1体ずつ確かめる（ボスの間に入って、2段目・技・攻撃の入り方）。

## 6. エリア

- 4つの地方（山岳・草原・廃城・溶岩）に、それぞれ寄り道のエリアを3つ足す（隠しボス2つと塔の回廊を合わせて、全部で45エリア）。
  - 山岳：凍った湖（山すその西）・鷹の巣（雪の峠の東）・吹雪の谷（雪の峠の西）
  - 草原：沼の小道（草原の入口の南）・風車の跡（沼の小道と風見の休み場につながる）・果ての草原（花の丘と背高草の野の北）
  - 廃城：古い墓地（城下の跡の東）・見張りの塔（古い墓地と崩れた兵舎につながる）・地下牢（城の中庭の西）
  - 溶岩：黒い森（灰の道の東）・硫黄の谷（溶岩の川の東）・灰の丘（火口のふちの東、硫黄の谷ともつながる）
- 寄り道のエリアには「地方の印」が1つずつある。ボスの間の前の門は、その地方の印を3つ持っていると開く。
  （たくさん探索してからボスを倒す形）
- 隠しボスのエリアは各地方に1つ（山岳：岩窟のぬし、溶岩：溶岩洞のぬし、草原：女王蜂、廃城：宝箱の王）。1エリアに1体。
  草原の「女王の巣」は果ての草原の西の帯の先（炎で茨を燃やす）、廃城の「宝物庫」は地下牢の西の帯の先（剣でつたを斬る）。
- 印は、寄り道のエリアのうち出口から遠く高い所に置く（探して登って取る）。印は死んでも墓石に入らない。
- 門の前に立つと「山岳の印が 3個 そろうと開く（あと2個）」のように出る。
- 神秘の塔にも1エリア足す（塔の回廊）。

## 7. ほかのバランス

- 回復薬の量を、いのちが増えた分だけ増やす（小10・中25）。癒しの魔法も10。たき火は全部戻る（今のまま）。
- 爆弾は30ダメージ（敵の体力が増えたので）。甲虫をひっくり返せる。
- 敵の落とすお金を増やす（4＋3×レベル＋0〜4。前は3＋2×レベル＋0〜3）。お店の値段はそのまま。
- 毒とやけどは毎秒2（前は1）。
- 敵に当たったあとの無敵は1秒のまま（体当たりは1秒に1回まで）。
- ほかに遊んで見つけた所は、ここに書き足す。
