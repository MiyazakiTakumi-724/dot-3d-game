## 1. 岩場のボスで止まるエラー

岩転がしの巨人の2段目で止まっていた。原因：砕けた大岩（と大蛇の影）の絵を先に消すと、「少しの間だけ出す絵」の一覧（`field._effects`）に消えた絵が残る。
それを型付きの変数に入れたとき、Godot が「解放済みの物は入れられない」で止まっていた。

- 直し：一覧から取り出すときは型なしの変数に入れて、`is_instance_valid` で確かめる（`_step_effects`・`_step_rollers`・`_step_lobs`）。
- テスト：`tests/test_bosses.gd` の `test_effects_freed_elsewhere_do_not_stop_the_game`・`test_giant_boulders_break_cleanly`（直す前は止まる）。
- 11体のボスの間で、それぞれ長く戦わせて（一時的な耐久テスト）、エラーが出ないことを確かめた。

## 2. 伸びとダメージの式

### 2.1 レベルの伸び【提案】

| | 前 | 今 |
|---|---|---|
| レベル1つでもらうポイント | 2 | 1 |
| いのち1ポイント | ＋3 | ＋2 |
| 体の動き1ポイント | 足＋3% | 足＋2% |
| 次のレベルまでの経験値（レベル n → n+1） | 5 × n | 4 × n × n |

経験値は、はじめは前と同じくらい（Lv1→2 は 4、Lv2→3 は 16）で、レベルが上がるほど重くなる。Lv10 までに 1140、Lv15 までに 4060。

### 2.2 ダメージの式【提案】

前の式は、つよさ1ポイントで攻撃が2割伸び、武器のポイントも1つで1割伸び、さらに鉄球はレベルで勝手に1割ずつ伸びていた。掛け算が重なって、レベルが上がるとすぐ強くなりすぎた。

- つよさの基本を5から10にして、どの武器の倍率も半分にした。はじめのダメージは前と同じで、つよさ1ポイントで伸びるのは前の半分（1割）。
  - 鉄球：つよさ × 0.5 ×（1 ＋ 落とした高さ × 0.5）。レベルで勝手に伸びる分はやめた。
  - 剣：つよさ × 0.3 ×（1 ＋ 剣のポイント × 0.05）×（落下斬り）。
  - 弓：つよさ × 0.5 × チャージ率 × 矢の倍率 ×（1 ＋ 弓のポイント × 0.05）×（高所射撃）。
  - 魔法：つよさ × 0.5 × 魔法の倍率 ×（1 ＋ 魔法のポイント × 0.05）。
- 武器のポイントは1つで5%（前は10%）。
- 装備のランク1つで、つよさ＋3（前は＋2。つよさの基本が倍になったので、ランク5で＋12）。
- 敵の体力と攻撃力は、レベル1つで15%ずつ伸びる（前は20%。主人公の伸びを下げたので合わせた）。

## 3. 装備のレベル制限をやめて、強い敵だけが落とす素材に

- 装備に付けていた「ランク3は Lv6、4は Lv12、5は Lv18 から」の制限（`ItemCatalog.RANK_LEVEL`）をやめた。持っていればどれでも装備できる。
- かわりに、強い敵からしか落ちない素材を2つ足した【提案】：
  - 力の結晶：レベル6以上の敵が20%で落とす（擬態箱は50%）。ランク4を作るのに2つ要る。
  - いにしえの結晶：レベル10以上の敵が12%で落とす（擬態箱は50%）。ランク5を作るのに3つ要る。
- 敵のレベルは、地方のレベル＋敵ごとのレベル＋倒したボスの数（前と同じ）。ボスを倒して敵が強くなるほど、結晶が落ちるようになる。
- ボスが落とす素材（ランク4の材料）はそのまま。ボスを倒しても、結晶がそろうまではランク4を作れない。

## 4. 地図・方位・たき火のエリア・敵の段差

### 4.1 全体マップ（M キー）

- 右上に方位（マップの上が北）。
- 自分のいる所（点滅する点）と、いま画面の上がどちらを向いているか（点から出る矢印）。画面の上へ歩くと、矢印の向きへ進む。
- 出口（次のエリアへの道）を、エリアのふちの黄色い印で出す。
- 門：閉じている門は赤い印（2本の柵）、開けた門は緑の印。
- 行ったことのないとなりのエリアは、うすい枠と「？」で出す（どこへ行けるかは分かるが、中は分からない）。
- 下に色の説明（黄：次への道　赤：閉じた門　緑：開けた門　橙：たき火）。

### 4.2 画面の方位

画面の右上（いのちのバーの下）に、カメラと一緒に回る方位を出す（赤い針が北、「北」の字）。全体マップの方位と同じ向き。

### 4.3 たき火のエリア【提案】

4つの地方と塔の、たき火のある休憩所のエリアをせまくして、敵をなくした。

- たき火のまわりの小さな台地（だ円）と、出口へ向かう幅3マスの道だけを残し、ほかは島の外（奈落）にした（`gen.py` の `carve_rest`）。
- 歩ける所は130マス以下で、エリアの半分以下（`test_bonfire_areas_are_small_and_safe`）。
- 塔の入口（tw_1）も広場を小さくして、敵をなくした。

### 4.4 敵の段差【提案】

イノシシのほかは、どの敵も1段登れる（前はスライム・射手・甲虫が登れなかった）。イノシシはまっすぐ突進する敵なので、登らないままにした（段差で突進を止められる）。

## 5. ボスの技と動き【提案】

どのボスにも技を足した。1段目から使う技と、体力が半分を切った2段目で増える技がある。
印（ひび・輪・炎）が先に出てから当たるので、見てよければよけられる。

| ボス | 1段目に足した技 | 2段目に足した技 |
|---|---|---|
| 岩転がしの巨人 | 7秒ごとに地面を叩き、主人公の足元（2×2マス）にひびを入れる。1.3秒後に奈落になり、5秒で元に戻る。落ちると死ぬ | 5.5秒ごとになり、巨人から主人公へ向かう7マスの列も割れる |
| 草むらの大蛇 | 体が見えているとき、少し離れていると、ためて突進して噛みつく | 地面から出たとき、まわりの土が盛り上がる（輪の印6つ） |
| 満ち引きする溶岩 | 引いているとき、溶岩の玉も落とす（2つおきに2個） | 炎の車輪が部屋を転がる |
| 廃城の主 | 離れると、剣を振って3方向に衝撃波 | 地面を割る（主人公へ向かう6つの印が、手前から順に弾ける） |
| 岩窟のぬし | 8秒ごとに地響きで、まわりに奈落を開ける（足元と、2〜3.5マス先の6マス） | 大岩を転がしてくる |
| 溶岩洞のぬし | 離れると、ためて火を5方向に吐く | 火の雨（主人公のまわりに3つ） |
| 双子 | 前に立つ方が、ためて突進する | 後ろの方も3方向に撃つ |
| らせん塔の番人 | 6秒ごとに、床に十字の印が出て火柱が立つ（4方向×2〜4マス） | まっすぐの十字と斜めの十字が交互 |
| ブライト | 10秒ごとに別の所へ消えて現れる（背中を取り直す） | 回る光の柱の列（4本×4つ） |
| 女王蜂 | 7秒ごとに針を8方向に撃つ | 急降下して降りたときにも8方向 |
| 宝箱の王 | 5秒ごとに本物だけが口を開けて金貨を3つ吐く（見分ける合図にもなる） | 擬態箱を1つ呼ぶ（いないときだけ） |

### 5.1 一時的な奈落（`field.boss_pits`）

- `boss_pits(マス, ひびの秒, 開いている秒)`：先にひびの印を出し、時間が来たら奈落にする（`HeightMap.set_pit`）。時間が過ぎると元の地面に戻す。
- 開かない所：出口のそば（`entry_safe_cells`）、敵やボスのいるマス、地面の鉄球や落とし物のあるマス、壁・水・奈落・島の外・ふさぐもの。
  鉄球や落とし物をなくさないため、出口のそばはエリアに戻れなくならないため。
- 開いたときに主人公がそのマスに立っていると、落ちて死ぬ（いつもの奈落と同じ。墓石はたき火のそばへ）。
- エリアを出ると、開いている奈落はなくなる。
