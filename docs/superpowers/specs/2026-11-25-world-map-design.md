# 大陸の全体を作る（全エリアの地図）設計

日付：2026-11-25
前提：`docs/design.md`（全体の仕様。6・7・8・9・12章）、`docs/superpowers/specs/2026-11-24-world-areas-design.md`（試作3。エリア・出口・切り替えの仕組みはそのまま使う）。

ユーザーの依頼（2026-11-25）：「決まってる範囲でマップ全体の作成に取り組んでほしい。ボス以外の敵はまだ実装しないでいい」。

表記のルール
- 印がない項目は、design.md などでユーザーが決めたこと。
- 【Claudeの判断】は、決まっていない所をClaudeが埋めたもの。直したい所があれば言ってもらう。

---

## 1. 決まっていること（ここから組み立てる）

- 1つの大陸がエリアに分かれている。今いるエリアだけを描く。エリアの端は見えない壁で、矢印の端からとなりへ。クリアはない。
- 地方は「山岳」「草原」「溶岩」「廃城」と、最後の「神秘の塔」。1つの地方は5エリアくらい。ボスは地方ごとに1体。神秘の塔にはボスが3体（双子・らせん塔の番人・ブライト）。
- 神秘の塔以外は、好きな順番で回れる。
- ボスの落とし物：山岳→剣、草原→弓、溶岩→（エアガンだったので見直す）、廃城→防具一式。たまに隠しボスがいる。
- チェックポイントは、街や明らかな休憩所のたき火。頻度はたまに。お店は町のエリアと旅の商人。
- ショートカット（チェックポイントへ戻る扉やはしご）をいろいろな所に置く。
- 新しい武器で今まで行けなかった場所へ行ける（例：鉄球で床を割る、弓で遠くのスイッチを撃って橋を下ろす）。最低ランクの武器で解ける。
- 地形は屋外の自然なもの。高さはこまめに変え、読みやすく。各エリアに1つ、カメラを回すと見える隠しもの。
- 見た目は主人公・地形・小物と同じ2倍の細かさ。
- 通常の敵は今回は置かない（今ある4エリアの敵はそのまま）。

## 2. 大陸の並び【Claudeの判断】

今の4エリア（野営地・岩場・丘陵・奥の森）を「はじまりの地」として大陸の真ん中に残し、その四方に地方をつなぐ。

```
                    [廃城 ×5]
                        │
                    [奥の森]
                        │（門）
[山岳 ×5] ─ [岩場] ─ [野営地] ─ [丘陵] ─ [草原 ×5]
                        │
         [神秘の塔×4] ─ [町]
              （封印）   │
                    [溶岩 ×5]
```

- 町：野営地の南。たき火とお店（商人）がある安全なエリア。
- 山岳は岩場の西、草原は丘陵の東、廃城は奥の森の北、溶岩は町の南から入る。
- 神秘の塔は町の西。入口は「封印の門」で閉じていて、4つの地方のボスをすべて倒すと開く（design.md の「神秘の塔は最後」を、通れる条件にしたもの）。
- エリアは全部で 4（はじまり）＋1（町）＋5×4（地方）＋4（塔）＋2（隠しボス）＝31。

## 3. 地方の中の並び【Claudeの判断】

どの地方も同じ骨組みにする（中身の地形は地方ごとに変える）。

```
[入口] → [休憩所（たき火）] → [奥1] → [奥2] → [ボスの間]
              ↑                          │
              └──── 近道の門（奥2の側から開ける）
```

- 入口：はじまりの地とつながる、地方の空気がわかるエリア。
- 休憩所：たき火がある（チェックポイント）。草原と廃城の休憩所には旅の商人がいる。
- 奥1・奥2：段差の多い探検のエリア。奥2から休憩所へ戻る近道の門がある（試作3の奥の森の門と同じ）。
- ボスの間：ボスと戦うための形にした広場（4章）。ボスはまだ動かさず、居場所に「ボスの像」を置く。
- 地方の中の本道は、最初から持っている物（鉄球）と、最低ランクの武器だけで通れる。好きな順で回れるので、ほかの地方のボスの武器が本道に要らないようにする。
- 武器で開く仕掛けは、寄り道（宝箱・隠しボス・近道）にだけ置く。ほかの地方で手に入れた武器を持って戻ると、前に行けなかった所に行ける。

## 4. 地方ごとの中身

| 地方 | 地形 | ボスの間（ボスの戦い方に合わせる） |
|---|---|---|
| 山岳 | 岩の多い高い崖（0〜8段）、高い所は雪 | 高い岩棚に巨人の像。像の足場はひびの入った岩で、上から鉄球で割れる形 |
| 草原 | ゆるい段々の広い野原、背の高い草むら、花、小川 | 背の高い草が一面に生えた広場。カメラを回すと草のすき間から奥が見える |
| 溶岩 | 黒い岩と溶岩の川（入れない）、湯気 | 低いくぼ地を溶岩が囲み、高い島が点々とある（溶岩の満ち引きはボスを作るとき） |
| 廃城 | 石畳、崩れた石の壁と柱、草 | 屋根の落ちた広間。崩れた壁の上（高い所）を回れる |
| 神秘の塔 | 白い石の床、柱 | ふもと → 塔の中（双子の間）→ 塔の外周（らせんに登る、番人）→ 最上階（ブライト） |

- 【Claudeの判断】溶岩のボスの落とし物は、エアガンの代わりに「炎の杖」（杖の最低ランクの炎のもの）にする。
- 【Claudeの判断】隠しボスは2体：山岳の奥1から弓の仕掛けで行ける「岩窟」、溶岩の奥2から剣の仕掛けで行ける「溶岩洞」。どちらも本道からは見えるが、行き方が分からない所に置く。

## 5. 武器で開く仕掛け【Claudeの判断】

| 仕掛け | 開け方 | 開くと |
|---|---|---|
| ひびの入った岩 | 上から鉄球を落とす（高さ1段以上から） | 岩が砕けて通れる |
| 的と上がった橋 | 弓で的を撃つ（山なりなので、崖の向こうの的にも届く） | 橋が下りて、川や奈落を渡れる |
| 茨 | 炎の魔法を当てる | 燃えてなくなる |
| つた | 剣で斬る | 切れて通れる |

- 一度開けた仕掛けは、死んでも開いたまま（門と同じ）。
- 鉄球の岩は本道にも置く（はじまりから持っているので）。弓・炎・剣の仕掛けは寄り道だけ。
- 仕掛けには、ふつうのカメラの向きでは見えにくいもの（崖の裏の的など）も混ぜる。高さとカメラを使う場面を増やすため。

## 6. たき火と死んだとき【Claudeの判断】

- たき火は野営地・町・各地方の休憩所・神秘の塔のふもとにある。
- 最後に近づいたたき火が、死んだときに戻る所になる（今は野営地だけ）。

## 7. 町とお店【Claudeの判断】

- 町には家（中には入れない）、井戸、たき火、商人が2人（武器屋・道具屋）いる。
- 旅の商人は、草原と廃城の休憩所にいる。
- 今回は商人を置くだけにし、近づくと「お店はまだ準備中」と出す。買い物の画面と値段は、次に作る（商品や値段は決まっていないため）。

## 8. 全体マップの画面【Claudeの判断】

- M キーで、行ったことのあるエリアの長方形を大陸の上に並べて見せる。今いるエリア・たき火・墓石のあるエリアに印を付ける。エリアの名前も出す。
- 行ったことのないエリアは描かない（探検の楽しみを残すため）。

## 9. やらないこと

- 通常の敵（新しいエリアには置かない）。ボスの動きと戦い（像を置くだけ）。
- お店の買い物。溶岩の満ち引き。セーブ。
- 野営地の、試しの武器の宝箱はそのまま（ボスができたら落とし物に移す）。

## 10. 作り方

- 地図は今と同じく `tools/area_maps/gen.py` で作る。地方ごとの作り方（地形・飾り）を足し、エリアの置き方と出口は表にまとめる。
- 新しい地面と物：雪、背の高い草（歩けて、キャラが少し隠れる）、溶岩（水と同じく入れない）、石畳、石の壁・柱、家、井戸、商人、ボスの像、仕掛け4つ。どれも2倍の細かさで作る。
- 仕掛けのルール、たき火の切り替え、封印の門、行ったエリアの記録は `scripts/rules/` に、先にテストを書いて作る。
- テスト：すべての出口が相手と重なる、エリアが重ならない、本道が鉄球だけで通れる（仕掛けを開けずに、はじまりから全ボスの間まで行ける。塔は封印を開けて）、くぼみがない、近道が開く、など。
