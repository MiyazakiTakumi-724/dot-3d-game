# 独自の開発1：Steamリリースに向けて（2026-11-26）

ユーザーの依頼（2026-11-26 13:44）：

> 一回独自に開発を進めてみてほしい／正式steamリリースを目指している／UIのチェックは忘れずに／
> 大事なのは高低差を活かした戦いとカメラの回転／参考にしたいゲームはcorekeeperやテラリア／ストーリーももっと深く凝ったものにしてみて

何をどの順で作るかは、Claudeが決めた。この文書の項目はすべて【提案】（ユーザーの明確な承認はまだない）。
design.md でユーザーが決めたこと（下から上へは攻撃できない、高さでダメージが増えるのは鉄球と弓の技能「高所射撃」だけ、など）は変えない。

## 0. 決めた順番と理由

1. **Steamに出すのに欠けている土台**：セーブとロード、タイトル画面、止める画面（Esc）、設定の保存。
   今のゲームは閉じるとすべて消え、タイトルもない。これがないと製品にならないので、最初に作る。
2. **高低差の戦い**：敵を崖から突き落とす、鉤縄、転がる岩、足場を崩す敵（design.md 12章でユーザーが採用した案）。
3. **カメラの回転**：見る向きで現れる「幻の足場」、鏡の敵（design.md 12章でユーザーが採用した案）、
   カメラを回している間だけ時間がゆっくり進む設定（design.md 5章でユーザーが「後で付ける」と決めたもの）。
4. **Core Keeper とテラリアから**：装飾品（テラリアのアクセサリーのように、できることが増える品物）、図鑑と記録のページ。
5. **ストーリーを深くする**：記憶のかけら、町の人の話の続きと頼みごと、本当の終わり。
6. **UIのチェック**：すべての画面を撮って、見切れ・重なり・読みにくさを直す。

ゲームパッドは承認済み（design.md 16章）だが、メニューをすべてパッドで動かす作業が大きいので、次の回にまわす。

## 1. Steamの土台（できた）

- **ゲームの名前**：「灯りの瞳 ― Lantern Eye ―」。主人公の、向きを変えて物の本当の姿を見る力の名前（4章）。`project.godot` の名前と、保存の場所（`user://` → LanternEye）。
- **セーブ**（`SaveGame`・`RunState.to_dict`）：3つの枠（`user://save_N.json`、書いてから名前を替えるので途中で切れても壊れない）。
  たき火で休んだとき・エリアを移ったとき・ボスを倒したとき・止める画面からタイトルへ／おわるとき・ウィンドウを閉じたときにセーブする。
  持ち物・装備・ステータス・墓石・チェックポイント・拾い済み・開けた門と仕掛け・行ったエリア・たき火・クリア・遊んだ時間・進み具合（flags）・倒した敵の数。
  つづきからは、最後に休んだたき火から始まる。
- **タイトル画面**（`TitleMenu`）：うしろで町をカメラがゆっくり回る。つづきから（枠を選ぶ。Lv・遊んだ時間・いる所・倒したぬし）・はじめから（使っている枠は上書きを確かめる）・設定・おわる。
- **止める画面**（`PauseMenu`、Esc）：世界を止める。つづける・設定・セーブしてタイトルへ・セーブしてゲームをおわる。
- **設定**（`SettingsPanel`）：インベントリ・止める画面・タイトルで同じ欄。`user://settings.json` に保存。
  足したもの：画面のゆれ（なしにできる）・カメラを回す間（ゆっくりにすると、Q/E と右ドラッグの間だけ時間が 0.35倍）。

## 2. 高低差の戦い（できた）

- **敵を崖から落とす**：剣（突き・落下斬り・回転斬りは強く）・鉄球・爆弾で敵を押す（矢と魔法は押さない）。
  押された敵は何段でも落ちるが、登れず、壁と水には入らない。落ちた段数で痛い（最大いのち×0.15×（段数−1））。奈落なら倒れる。
  盾持ちと甲虫は押しにくく（半分）、飛ぶ敵・火の玉・亡霊・黒騎士・擬態箱は動かない。
- **鉤縄**（道具屋で80G、R）：カーソルの所へ投げる。1〜3段上の地面のふち（56pxまで）へ体を引き上げる。
  敵なら手前へ引き寄せる（高い所の敵は引きずり下ろして、落ちた段数で痛い）。1秒に1回。
- **転がる岩**（`Boulder`）：崖のふちの高い所に置いてある（エリアの広さで1〜3つ、町・広場・ボスの間にはない。いまは25か所）。
  F・剣・鉄球・爆弾で押すと、押した向きへまっすぐ転がる。低い所へは落ちて、落ちた段数ほど速く痛い（敵の最大いのち×（0.3＋0.15×段数））。
  同じ高さか高い所・壁にぶつかると砕け、ひびの岩ともろい壁なら壊す。奈落・島の外へは落ちて消え、水に沈む。ボスの構えを大きく崩す。
  細い道をふさぐ所には置かない。エリアに入り直すと元に戻る。
- 足場を崩す敵は、次の回にまわした（新しい敵の種類は地図の作り直しが要るため）。

## 3. カメラの回転（できた）

- **幻の橋**（`PhantomBridge`）：高い所のふちの床に「瞳の印」がある。印の目が向く方を画面の上にして見たとき（±26°）だけ、
  向こうの柱へ渡る青白い橋が見えて、歩ける。少し外れた向きでは うすく光るので、回しながら探せる。
  橋の上でほかの向きへ回すと、0.6秒で消えて下の地面へ落ちる（橋の下は奈落・水でない低い地面なので、死なない）。
  向こうの柱は、地図に行けない同じ高さの所がなければ、低い地面に2×2の柱を立てて作る（まわりはつながったまま、登っては行けない）。
  18エリアにある。印の上では「目の向く方を 画面の上にして 見る（Q/E）」と出る。
- **カメラを回す間ゆっくり**：設定（1章）。
- 鏡の敵は、次の回にまわした。

## 4. ストーリーを深くする（できた）

ユーザーが決めた筋（村が魔物に襲われ、主人公だけが近くの町の人に助けられた）はそのまま。その奥を足した：

- 灯りの村は、塔の上の目（ブライト）を眠らせておく火「灯り」を守る村だった。灯り守は「灯りの瞳」（向きを変えて本当の姿を見る力）を持つ。
- 闇の王の正体は**ガルド**。主人公の母リナの兄で、灯りの騎士。狩人のセナの相棒だった。
  ひらきかけた目を閉じようと、セナを塔の下に残してひとりで登り、目の光に取りこまれた。目は灯りを消すために、ガルドに村を焼かせた。
  母は最後に、主人公の胸に灯りをともした（はじまりの言葉に足した）。だから主人公だけが霧の中で生きのび、幻の橋が見える。
- **記憶のかけら**（12）：ガルドの記憶。幻の橋の向こうの宝箱にある（はじまりの地2・各地方2・霧の谷2）。拾うと言葉が出て、記録のページで読み返せる。
- 人の言葉：セナ（かけら4つで「声に覚えがある」、8つで「ガルドは相棒だった」、ガルドを眠らせたあと）、町長（灯りの村の言い伝え）、
  村長のまぼろし（かけら8つで黒い王の正体）、子どものハナ（鉤縄）、物知りのおばあさん（崖のふちで斬ると落ちる）。
- かけらを すべて集めて闇の王を倒すと、ガルドが自分を取り戻す場面になる。そのあとブライトを倒すと、**本当の終わり**（村に灯りをともす）。

  羽根のマント（飛び降り＋2段）・岩の手袋（押す距離と岩のダメージ1.5倍）・鷹の目（弓の届く距離1.25倍）・月の指輪（マナの戻り1.5倍）・
  狩人の矢筒（4本に1本、矢が減らない）・瞳の首飾り（幻の橋が広い向きから見える）・登山靴（2段をすばやく よじ登る）。

## 8. 遊んでみての直し（2026-11-27 1:50、ユーザーの指示）

- 看板を読む・人と話している間は、カメラを回せない（`StackCamera.locked`。field.gd が話す画面の開いている間だけ立てる）。
- 同じ看板を何か所にも置かない：仕掛けのヒントの看板は、その種類の仕掛けがあるエリアのうち、はじめに入ったエリアにだけ置く
  （`run.flags["hint_sign:<種類>"]` にエリアを覚える。セーブに入る）。ほかのエリアには置かない。そのエリアの仕掛けを開けると看板も消える。
- 町の人（と各地方の旅人）が歩きまわる（`Wanderer`）【提案】：家のまわり4マスの、まわり8マスも同じ高さの平らな所だけを、
  1マスずつゆっくり（18px／秒）歩き、1.5〜4.5秒立ち止まる。歩いている間は出たマスと向かうマスをふさぐ。主人公・敵・鉄球・ほかの人のそばへは行かない。
  話しかけると、こちらを向いて3秒立ち止まる。看板・墓と、村長のまぼろし（たき火のそばで待っている）は動かない。
- 村人の言葉を、その人らしい話し方に書き直した【提案】：セナはぶっきらぼうで優しい狩人、町長は「〜じゃ」の年寄り、ミロは元気な弟子、
  ハナは子ども、おばあさんはおっとり、旅人は自分がやられた話。攻略の手がかりは説明ではなく、体験やうわさとして話す。
  一度に話すのは1〜3ページ。話しかけるたびに、進み具合の話 → 世間話（`chat`、1人2〜4つ）を順に。進み具合が変わると、また新しい話から
  （`Story.next_words`。聞いたものは `run.flags` の heard:・chat: に覚える）。
