# 試作2「死と取り返しの流れ」設計

日付：2026-11-23（2026-11-24、遊んだ後の指摘で操作と世界観を手直し。10章が優先）
前提：`docs/design.md`（全体の仕様）、`docs/next-prototype-death-loop.md`（引き継ぎメモ）。

- 【Claudeの判断】が付いた項目は、ユーザーに聞かずにClaudeが決めたこと。ユーザーが読んで直せるように印を付けている。

## 1. 目的

死ぬ → チェックポイントから再開 → 墓石を取り返しに行く、という流れが「緊張感」になるか「面倒」になるかを確かめる。これがこのゲームの手触りの核なので、ボスや新しい武器より先に確かめる。

成功の目安：何度か死んで取り返しに行ったときに、「持ち物を取り返したい」「今度は死なずに行きたい」と感じること。
失敗（動いていても失敗とみなすもの）：歩き直しが長くて退屈、墓石がどこか分からなくて探すのが面倒、失うものが少なすぎて取り返す意味がない。

## 2. やること・やらないこと

やること
- 広いエリア1つ。チェックポイントのある安全地帯、敵のいる道、奥のショートカット扉、奈落。
- チェックポイント、墓石、死んだときの持ち物の扱い、ショートカット、拾えるもの、回復アイテム、強い鉄球。
- 死んだら、ステージを読み込み直さずに、その場で中身を戻してチェックポイントから再開する（作り方B）。

やらないこと
- 簡単モード（後で作る）。
- 範囲が広がる鉄球（もっと上のランク。後で作る）。
- 剣など鉄球以外の武器、レベルアップ、技能、お店、武器の強化。
- エリアのつなぎ（複数エリア）、マップのデータファイル化。
- CLAUDE.md の「既知の小さな問題」3つの修正。

## 3. 作り方（決定：B）

検討した2案：

- A. ステージを読み込み直す：持ち物などをステージの外に置き、死んだら書き換えてシーンを読み込み直す。敵の復活を書かなくて済み、作る量が少ない。死ぬたびに画面が切り替わる。
- B. ステージはそのままで中身だけ戻す：プレイヤーをチェックポイントへ移し、敵などを初期状態に戻す。切り替えがないが、戻し忘れが起きやすく、作る量とテストが増える。

Claudeは作る量の少なさからAを勧めたが、ユーザーは「後々Bに変える必要がありそう」としてBを選んだ。

Bで作るときの決まり
- 「死んだら何を戻すか」は、ルール側（`scripts/rules/`）で一か所にまとめて決め、単体テストする。ステージ側は、その結果に合わせてノードを作り直す・消すだけにする。
- 戻すもの：敵（全員、初期位置・初期の向き・最大体力で復活）、飛んでいる敵の弾（すべて消す）、プレイヤー（チェックポイントへ移動、体力は最大）。
- 戻さないもの：拾い済みのお金・アイテム（復活しない）、開けたショートカット（開いたまま）、墓石（死んだ場所に残る）、経験値。
- 【Claudeの判断】倒した敵のノードは今 `queue_free` しているので、死んだときは敵の初期配置の表からノードを作り直す。ノードを隠して使い回す方法でもよい（実装者の判断）。

## 4. ルールの中身

### 4.1 持ち物とお金

- プレイヤーが持つもの：お金、素材、回復アイテム、鉄球（普通の鉄球と強い鉄球）、経験値。
- 死ぬと：
  - お金は半分が墓石に入り、半分は手元に残る。【Claudeの判断】奇数のときは、墓石に入る方を切り捨てる（手元に多く残す）。
  - 素材、回復アイテム、強い鉄球は、すべて墓石に入る。
  - 普通の鉄球（鉄球の最低ランク）は手元に残る。
  - 経験値は手元に残る。
- 【Claudeの判断】経験値は数字として貯まるだけで、この試作ではレベルは上がらない。
- インベントリの所持数に制限はない。

### 4.2 墓石

- 死んだマスに置かれ、4.1で墓石に入るものをすべて入れる。
- 世界に1つだけ。墓石が残っている状態でもう一度死ぬと、古い墓石は中身ごと消え、新しい墓石ができる。
- 叩いて壊すと中身がすべて手元に戻り、墓石は消える。
- 攻撃が当たれば壊れる。一撃で壊れる。この試作の武器は鉄球だけなので、墓石のマスに鉄球を落とせば壊れる（平らな所で落とした1ダメージでも壊れる）。
- 【Claudeの判断】墓石を壊せるのはプレイヤーの攻撃だけ。敵の弾は墓石で止まり（壁と同じ）、壊さない。敵も墓石の前で引き返す。
- 墓石は通れない（壁と同じ扱い）。【Claudeの判断】通れると、上に立って鉄球を落とせないため。鉄球は「目の前のマス」に落とすので、墓石の隣から落とす。
- 【Claudeの判断】墓石は、遠くからも見つけやすいように背の高い目立つ形と色にする。場所を示す矢印などは付けない（探す手間が面倒になるかどうかも、試作で確かめたいことの一つ）。

### 4.3 落下死と奈落

- マップの外はない（今どおり、外は壁として扱う）。
- 新しいマスの種類「奈落」を足す。歩いて踏み込むと落ちて死ぬ。
- 奈落で死んだときは、墓石を奈落に置かず、落ちる直前に立っていたマスに置く。
- 【Claudeの判断】敵は奈落に入らない（今の「高さの違うマスに来たら引き返す」と同じく引き返す）。
- 【Claudeの判断】鉄球は奈落のマスには落とせない（壁と同じく、落とす操作が失敗する）。鉄球をなくすことは起こさない。
- 【Claudeの判断】奈落の見た目は、地面のない真っ暗なマスにする。踏み込んでから死ぬまでに、落ちていく短い演出（0.5秒ほど、キャラが沈んで消える）を入れる。

### 4.4 チェックポイント

- 敵のいない安全地帯に1つ置く。休憩所と分かる見た目にする（たき火など）。
- 死んだらここで再開する。
- ここで全回復する。【Claudeの判断】チェックポイントのマスに近づく（隣か上に立つ）と自動で全回復する。休むための操作や、休んだときの敵の復活はこの試作では入れない。
- 戦闘中に頼れるのは回復アイテムだけ（チェックポイントは安全地帯にしかないため）。

### 4.5 回復アイテム

- エリアのところどころに置いてあり、拾える。使うとその場で体力が回復する。
- 持ち物なので、死ぬと墓石に入る。
- 【Claudeの判断】1つで体力を1回復する（最大3を超えない）。体力が最大のときは使えない。~~使うキーは C。~~ → 10章（2番を選んで左クリック）。

### 4.6 鉄球

- 普通の鉄球：今と同じ。ダメージ＝落ちた段数＋1（最低1）。
- 強い鉄球：ダメージ＝落ちた段数＋2。平らな所でも2ダメージ、1段から落とせば体力3の敵を一撃で倒せる。範囲は普通の鉄球と同じ（目の前の1マス）。
- 強い鉄球はエリアの中に1つ置いてあり、拾うと手に入る。
- 鉄球は1つずつ使う。場に出せる鉄球はいつも1つで、落としたら拾い直すまで次は落とせない（試作1と同じ手触り）。普通と強いの切り替えは、鉄球を手に持っているときだけできる。
- ~~【Claudeの判断】切り替えのキーは 1（普通）と 2（強い）。~~ → 10章（インベントリで前もって決める）。
- 【Claudeの判断】落として地面にある鉄球も持ち物として数える。強い鉄球を地面に置いたまま死んだら、強い鉄球は墓石に入り、手には普通の鉄球が戻る。普通の鉄球を地面に置いたまま死んだら、普通の鉄球は手元に戻る。どちらの場合も、地面の鉄球は消える。

### 4.7 敵

- 死ぬと、倒した敵も含めて全員が初期の状態で復活する。
- 【Claudeの判断】敵は倒すとお金を落とす（1体につき固定額、仮に10）と経験値（仮に1）。倒した瞬間に手元に入る（拾いに行く必要はない）。敵からの素材やレアドロップはこの試作では入れない。
- 【Claudeの判断】敵の動きと弾は試作1のまま（往復して2秒ごとに撃つ）。

### 4.8 拾えるもの

- お金、素材、回復アイテム、強い鉄球（1つ）。マップに置いてあり、上を歩くと拾う。
- 一度拾ったものは、死んでも復活しない。
- 【Claudeの判断】素材は数が増えるだけで、使い道はこの試作にはない。種類は1種類。

### 4.9 ショートカット

- エリアの奥側から開けられる扉。開けるとチェックポイント近くへ戻る近道になる。
- 一度開けたら、死んでも開いたまま。
- 【Claudeの判断】扉は閉じている間は壁として扱う。奥側（チェックポイントから遠い側）の隣のマスに立って向き合い、F で開ける（10章）。手前側からは開けられない。

## 5. エリア

- 1つの広いマップ。試作1（16×12マス）の数倍。~~【Claudeの判断】40×28マスくらい。~~ → 10章（屋外の地形）。
- マップは今と同じく、コードの中の文字の地図で書く。奈落、チェックポイント、扉、拾えるものの記号を足す。
- 置き方の考え方：
  - 片方の端にチェックポイントのある安全地帯（敵なし）。
  - そこから奥へ、台地と敵のいる道が続く。チェックポイントから奥まで、歩いて1分以上かかる距離。
  - 道の途中に、奈落の横を通る細い道を作る。
  - 奥に強い鉄球と、ショートカットの扉。扉を開けると安全地帯の近くへ戻れる。
- 【Claudeの判断】ゴールを1つ置く（奥の出口）。たどり着くと「CLEAR」と出る。何をすればよいかが分からないと、取り返しの流れが試せないため。敵の全滅はクリア条件にしない。
- ゲームオーバーはなくなる（死んだら必ずチェックポイントから再開する）。
- 【Claudeの判断】マスの数が試作1の約6倍になるので、描画が重くないかを実機で確かめる。重ければ、画面の外のマスを描かない処理を足す（design.md 8章の【提案】）。

## 6. 死んだときの流れ（画面）

1. 体力が0になる、または奈落に落ちる。
2. 操作できなくなり、「YOU DIED」と出る。【Claudeの判断】1.5秒ほど。
3. 4.1〜4.2のとおり墓石ができ、持ち物が移る。
4. 3章のとおり敵などを戻し、プレイヤーをチェックポイントに置く。体力は最大。
5. 操作できるようになる。

## 10. 手直し（2026-11-24、ユーザーが遊んだ後の指摘）

ユーザーが試作を遊んで、操作と世界観が違うと指摘した。操作は `docs/design.md` 5章にもともと書いてあった（Claudeが試作1のキー操作を引き継いでしまった）。以下はすべてユーザーが決めたか、Claudeの案をユーザーが「全ての案採用」と承認したもの。ここに書いたことは、上の章より優先する。

### 10.1 操作

- 左クリック：手に持っているアイテムを使う。鉄球なら落とす。
- 鉄球は、マウスカーソルの方向の「目の前のマス」に落とす。プレイヤーは歩く向きとは別に、いつもカーソルの方を向く（動きながら狙いを変えられる）。
- キーボードの数字キーで、手に持つアイテムを選ぶ。今は 1＝鉄球、2＝回復アイテム。回復も「2を選んで左クリック」で使う。
- 鉄球の種類（普通・強い）は、インベントリ画面で前もって決めたものを使う。1/2での種類の切り替えはなくす。
- Tab でインベントリ画面を開く。開いている間はゲームが止まる。
- 右ドラッグ、または Q/E でカメラを回す。左ドラッグでは回らない。
- 落とした鉄球は、上を歩くだけで拾う。
- 扉は、奥側から F で開ける。【Claudeの判断】門の奥側の前のマスに立てば向きは問わず、そこに立つと画面に「F: open the gate」と出る。

### 10.2 世界観とマップ

- 基本的に屋外。草地・木・岩山・水・崖がある自然の地形。ユーザーが見せた参考画像（ボクセルの島のような屋外）は雰囲気の参考にして、形や見た目はこのゲーム用に作る。
- 壁の代わりに、木や岩が弾よけになる（移動も弾も止める）。
- 水は入れない場所（弾は水の上を飛ぶ）。
- 奈落は崖の裂け目にする。
- 試作1のレンガの壁や、通路を折り返す迷路の形はやめる。

### 10.3 Claudeの判断（ユーザーに聞かずに決めたこと）

- 【Claudeの判断】インベントリでの鉄球の設定は「強い鉄球を使う」という好みとして覚えておく。死んで強い鉄球が墓石に入ると普通の鉄球になり、墓石を壊して取り返すと、設定し直さなくても強い鉄球に戻る。鉄球が地面にあるときは種類を変えられない（手に戻ってから反映される）。
- 【Claudeの判断】狙っているマス（鉄球が落ちるマス）に、地面の影のような印を出す（design.md 5章「狙っている高さは、地面に落ちる照準の影で見せる」）。
- 【Claudeの判断】鉄球は水や奈落のマスには落とせない。
- 【Claudeの判断】扉は木の門（岩や木のあいだの柵の門）にする。
- 【Claudeの判断】マップは「歩いて1分以上」を保つため、川・岩山・崖で道を大きく回り込ませる形にし、広さは64×40マスくらいにする。チェックポイントのある草地から外回りに1周して、最後に門を開けるとスタートの草地に戻れる。ゴールは、門のそばから入る中央の高台の上。
- 【Claudeの判断】試作1（stage_01）は X/Z の操作のまま残す。地形の描き方は共通なので、草や土の見た目は新しいものになる。
- 【Claudeの判断】鉄球は、カーソルに画面上で一番近い隣のマス（8方向、高さも含めて比べる）に落とす。高台から下を指しても斜めにずれないようにするため。

## 11. 2回目の手直し（2026-11-24、箱庭・日本語・簡単に・弾）

ユーザーが手直し後の試作を遊んで、次のように指摘した。ここに書いたことは、上の章より優先する。

- ステージは、参考画像のような「箱庭」のイメージ。もっと広く、上から見て四角である必要もない。
- ゲーム内のガイドは、日本語にできる所は日本語にする。
- 最初のステージなので、もう少し簡単にする。敵の体力は1で、遠距離攻撃はなし。
- 不具合：遠距離攻撃の弾が、高さが違っても当たる。壁で止まらない。

### 11.1 弾の当たり方（不具合の直し）

- 弾は、撃った敵が立っている高さを飛ぶ。
- 弾は、壁（木・岩・閉じた門・墓石・島の外）と、弾より高い地面（崖の側面）で止まる。
- 弾より低い所の上は、その高さのまま飛び越える（低い所にいるプレイヤーには当たらない）。
- 弾がプレイヤーに当たるのは、プレイヤーが弾と同じ高さに立っているときだけ。
- 試作2のエリアでは敵が撃たないので、この直しは試作1と、これから作る撃つ敵のためのもの。

### 11.2 最初のステージを簡単にする

- 敵の体力は1（どの鉄球でも1発で倒せる）。撃ってこない。
- 【Claudeの判断】撃たない代わりに、敵に体当たりされると（同じ高さで体が触れると）1ダメージ。ダメージを受けた後の1秒間は点滅して、もう一度ダメージを受けない。敵がまったく危なくないと、「死ぬ→取り返す」の流れを確かめられないため。
- 試作1（stage_01）の敵は、今のまま（体力3、弾を撃つ）。

### 11.3 日本語のガイド

- 【Claudeの判断】日本語のドット絵フォントとして PixelMplus（M+ FONT LICENSE：商用利用・改変・再配布が自由）を同梱する。320×180の画面に合う 10px と 12px がある。ライセンスの文は `fonts/` に一緒に置く。
- 画面の文字（体力・持ち物・手に持つアイテム・操作の説明・門のヒント・死んだとき・クリア・インベントリ画面）を日本語にする。キーの名前（Tab、F など）は英字のまま。

### 11.4 箱庭の見た目

- 島は、暗い背景の中に浮かぶ箱庭にする（海はなくす）。
- 島のふちでは、土と岩の断面が下へ伸びて見える。下の方は少しすぼまって、でこぼこにする。
- 地形は段々にする（高さ0〜5くらい）。高い所の川や池の水は、段のふちから滝になって下の段へ落ちる。島のふちからも滝が下へ落ちる。
- 草木を増やす：丸くて大きい木、とがった木、茂み、花。
- 【Claudeの判断】島のふちから落ちることはない（見えない壁）。落ちて死ぬのは奈落の裂け目だけ（ユーザーの「マップの外側はない」に合わせる）。
- 【Claudeの判断】茂みは木と同じく通れず、弾も止める。花は飾りで、上を歩ける。
- 【Claudeの判断】描画を軽くするため、地形の側面は、隣が低くて見える部分だけを描く。地形の絵は、カメラを回したときだけ描き直す。

### 11.5 箱庭のステージ

- 【Claudeの判断】今までの島（64×40）より広い、上から見て丸みのある形の島にする。ふちには入り江や出っ張りをつける。
- 死と取り返しの流れに必要なものは今までどおり：たき火の安全地帯、外回りの道（歩いて1分以上）、最後に開ける門（たき火のすぐ近くに戻れる）、奈落の裂け目、強い鉄球1つ、回復2つ以上、高台の上のゴール。
- 安全地帯には、敵が歩いて入ってこない（撃つ敵がいないので、「弾が届かない」の代わりに「歩いて近づけない」で確かめる）。
