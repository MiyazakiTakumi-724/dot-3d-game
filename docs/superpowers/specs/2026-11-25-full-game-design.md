# ゲームを完成まで作る（町・せまいエリア・敵・アイテム・素材・作る・ボス）設計

日付：2026-11-25
前提：`docs/design.md`、`docs/superpowers/specs/2026-11-25-world-map-design.md`（大陸の全体）。

ユーザーの依頼（2026-11-25 15:32、原文）：

> 野営地は町に作り替えて / 一つの区分はもっとせまく作って / 一回もう指示はしないから完成まで作って /
> 敵やアイテムも豊富に用意して / 一つのランクにも複数の種類のアイテムを用意して（アイテムはランク5までお願い） /
> アイテムそれぞれに特色をつけて（防具なら足早くなるやつとか） / ランク1のアイテムは効果なしかつ種類1つでいい /
> ボスからドロップするのはランク4のアイテム / 素材にもある程度の種類つけて / 素材でいろんな装備作れる /
> ドロップや作ることでしか手に入らない装備もあるけど入手手段豊富な装備もある / 宝箱限定の装備はなし /
> 最終的にランク5のアイテムは素材で作るものになる / 装備以外のアイテムもいろいろ用意しておいて /
> 初期アイテムは鉄球のみ / 説明しきれなかった部分は自分で補填して

この依頼で、前の決まりのうち次を変える：ランクは1〜10から1〜5へ。ボスの落とし物は「その武器の最低ランク」から「ランク4の品物」へ。
最初から持つ物は鉄球と無の杖から、鉄球だけへ。通常の敵を、すべてのエリアに置く。
ほかの所はすべて【Claudeの判断】で埋めた（ユーザーから「自分で補填して」と言われたため）。

## 1. 大陸の並び（作り直し）

- 野営地を「はじまりの町」に作り替える（家・井戸・たき火・道具屋・武器屋・鍛冶屋）。前の「町」のエリアはなくす。
- どのエリアもせまくする。前は最大 76×40 マスだったが、ふつうは 16×16〜24×20、長いエリアでも 32×14 にする。
- 骨組みは前と同じ：はじまりの地の四方に地方。地方は「入口 → 休憩所（たき火）→ 奥1 → 奥2 → ボスの間」で、奥2から休憩所へ近道の門。

```
                 [廃城 ×5]
                     │
 [山岳 ×6] ─ [岩場] ─ [町] ─ [丘陵] ─ [草原 ×5]
                     │  ＼
              （封印） │   [奥の森]（町の北、丘陵と近道の門）
          [神秘の塔×4]  [溶岩 ×6]
```

（実際の並び：奥の森は町の北、丘陵は町の東、岩場は町の西。廃城は奥の森の北、溶岩と神秘の塔は町の南。全部で30エリア）

- 地方の中は、休憩所・奥1が 16×16、奥2が 32×14（休憩所と奥1の両方に接して、近道の門を作る）、ボスの間が 24×20。

## 2. 品物の種類

品物は4つに分ける：装備・素材・道具・矢。すべて `ItemCatalog` に id で書く。

### 2.1 装備（5つの枠 × ランク1〜5）

- ランク1は枠ごとに1種類で、特色なし。ランク2は2種類、ランク3は3種類、ランク4は3種類、ランク5は2種類。
- ランクが1上がるごとに、つよさ＋2（防具は最大いのち＋4）。そのうえに、品物ごとの特色がつく。
- 手に入れ方：お店・作る（鍛冶屋）・敵の落とし物・ボスの落とし物。宝箱から出る装備もあるが、どれもお店か作るでも手に入る（宝箱だけの装備はない）。
- ランク4は、ボスの落とし物だけのもの・作るだけのもの・両方のものが混ざる。ランク5は作るだけ。

| 枠 | ランク1 | ランク2 | ランク3 | ランク4 | ランク5（作るだけ） |
|---|---|---|---|---|---|
| 鉄球 | 鉄球 | 重い鉄球（つよさ＋2）／広がる鉄球（当たる範囲×1.4） | とげ鉄球（毒）／鎖の鉄球（届く距離×1.5）／焼け玉（やけど） | 岩窟の鉄球（範囲×1.5・つよさ＋3、隠しボス）／溶岩の鉄球（やけど・範囲×1.3、隠しボス）／地鳴りの鉄球（遅くする・範囲×1.3） | 星の鉄球／流星の鉄球 |
| 剣 | 剣 | 軽い剣（振る速さ×1.3）／青銅の剣（つよさ＋2） | 毒の剣／長剣（届く長さ×1.4）／吸いとる剣（当てると いのち＋1） | 巨人の大剣（山岳のボス）／炎の剣（やけど）／霜の剣（遅くする） | 星の剣／王の剣 |
| 弓 | 弓 | 短弓（溜め×1.5）／長弓（届く距離×1.3） | 狩人の弓（素材が落ちやすい）／毒の弓／剛弓（つよさ＋3） | 大蛇の弓（草原のボス）／二連の弓（2本撃つ、双子）／風の弓（溜め×2） | 星の弓／日輪の弓 |
| 杖 | 無の杖 | 炎の小杖（火の玉）／氷の小杖（氷のつぶて） | 炎の杖（火の玉・火柱）／氷の杖（マナ×0.7）／癒しの杖（無の弾・癒し） | 溶岩の杖（溶岩のボス）／雷の杖（無の弾・雷）／霜の大杖（氷のつぶて・癒し、最大マナ＋15） | 星の杖（炎3つ）／嵐の杖（氷・雷・癒し） |
| 防具 | 布の服 | 革の服（守り1）／旅人の服（足＋10%） | 鎖かたびら（守り2）／斥候の服（足＋15%）／魔導の衣（最大マナ＋15） | 騎士の鎧（守り3、廃城のボス）／疾風の服（足＋25%、番人）／命の衣（5秒ごとに いのち＋1） | 星の鎧／竜鱗の鎧 |

- 守り：敵から受けるダメージがその数だけ減る（最低1）。
- 杖の魔法の数（ランク1〜5に合わせて直す）：1は1つ、2は1つ、3は1〜2、4は2つ、5は2〜3。
- 新しい魔法：氷のつぶて（まっすぐ飛び、当たった敵を3秒遅くする）、雷（狙った点に落ちる。高い所からでなくても、自分と同じかより低い所の敵に当たる。強い）、癒し（自分の いのち＋6）。

### 2.2 素材

- どこでも：獣の皮・骨・鉄くず・丈夫な枝・薬草
- 地方ごと：山岳（鉄鉱石・雪の結晶）、草原（蛇のうろこ・薬草が多い）、廃城（古い鋼・銀のかけら）、溶岩（黒曜石・火の石）、神秘の塔（星のかけら）
- ボスの素材：巨人の核・大蛇の牙・溶岩の心臓・城主の紋章・岩窟の宝石・火とかげの尾・双子の鏡・番人の歯車・ブライトの瞳
- ランク5の装備は、星のかけらとボスの素材で作る。

### 2.3 道具（手に持つ5番。ホイールで替える）

回復薬（いのち＋6）・回復薬・中（＋15）・回復薬・大（全部）・マナの薬（マナ＋30）・力の薬（30秒つよさ＋3）・
守りの薬（30秒守り＋2）・速さの薬（30秒足＋30%）・帰りの羽（最後のたき火へ戻る）・爆弾（カーソルの所へ投げる。まわりにダメージ）

### 2.4 矢

矢・毒矢・火矢（やけど）・鉄の矢（威力×1.5）。普通の矢のほかは、弓の技能「矢の種類」で使える（今の決まりのまま）。

## 3. お店と鍛冶屋

- 町：道具屋（道具と矢）、武器屋（ランク1の装備とランク2の一部）、鍛冶屋（素材とお金で作る）。
- 旅の商人（山岳・草原・廃城・溶岩の休憩所）：地方ごとに品ぞろえが違い、ランク3の装備も少し売る。
- 商人のそばで F を押すと、お店の画面が開く（開いている間も世界は動く）。品物の名前・ランク・特色・値段が並び、クリックで買う・作る。

## 4. 敵（すべてのエリアに置く）

| 敵 | 動き | 出る所 |
|---|---|---|
| スライム（敵1） | 往復、体当たり、段差なし | はじまり・草原 |
| ゴブリン（敵2） | 1段登って寄り、ためて叩く | はじまり・山岳・廃城 |
| 射手（撃つ敵） | 2秒ごとに撃つ | どこでも |
| 盾持ち | 正面からの剣・矢・魔法を防ぐ。鉄球（上から）と背中からは通る | 廃城・溶岩・塔 |
| 影 | 体が見えず、地面の影だけ見える。寄ってきて体当たり | 草原・塔 |
| コウモリ | 飛ぶ。段差・水・奈落の上も越えて、ふらふら寄ってくる | 山岳・溶岩・塔 |
| イノシシ | まっすぐ並ぶと、ためてから速く突進する | 山岳・草原 |
| 火の玉 | 寄ってきて、そばで弾ける（まわりにダメージ） | 溶岩 |
| 亡霊 | 足音を聞いて遠くから寄ってくる。しゃがんで歩くと気づかれにくい | 廃城・塔 |

- 敵のレベル：はじまり1、山岳・草原2、廃城・溶岩3、塔5（＋倒したボスの数）。
- 落とし物：お金（毎回）、その地方の素材（よく）、回復薬（ときどき）、装備（まれ。ランク1〜3、塔ではランク4も）。

## 5. ボス（9体。落とし物はランク4の品物とボスの素材）

| ボス | 場所 | 戦い方 | 落とし物 |
|---|---|---|---|
| 岩転がしの巨人 | 山岳 | 高い岩棚から岩を投げる。同じ高さまで登ると踏みつけ（ためてから、まわりに） | 巨人の大剣・巨人の核 |
| 草むらの大蛇 | 草原 | 背の高い草の中を動き、カメラの向きが合うときだけ姿が見える。ためてから噛みつく | 大蛇の弓・大蛇の牙 |
| 満ち引きする溶岩 | 溶岩 | 溶岩が満ちると低い所にいるとダメージ。引いたとき、低い所に顔を出して火を吐く | 溶岩の杖・溶岩の心臓 |
| 廃城の主 | 廃城 | 足音で追ってくる騎士。ためてから広く横に斬る（しゃがむか、高い壁の上へ逃げる） | 騎士の鎧・城主の紋章 |
| 岩窟のぬし（隠し） | 山岳 | ゆっくり寄り、ためて叩く。まわりに岩を落とす | 岩窟の鉄球・岩窟の宝石 |
| 溶岩洞のぬし（隠し） | 溶岩 | 速く走り回り、通った跡が燃える | 溶岩の鉄球・火とかげの尾 |
| 双子 | 塔 | 2体。片方はいつも、カメラから見てもう片方の真後ろに隠れるよう動く。カメラを回すと見分けられる | 二連の弓・双子の鏡 |
| らせん塔の番人 | 塔 | 塔の芯の前でゆっくり回る。背中の弱点にしか攻撃が効かない | 疾風の服・番人の歯車 |
| ブライト | 塔 | 背中の目が光をため（約1秒）、光る瞬間に目が画面の手前を向いていると画面が白くなる（1.5秒）。目（背中）にしか攻撃が効かない | ブライトの瞳。倒すとゲームの終わり（そのあとも遊べる） |

- 倒したボスは戻らない。死んだらボスは体力が戻る。4つの地方のボスを倒すと封印が開く（今のまま）。
- 画面が白く光る演出は、設定で弱められる。

## 6. 始まり

- 持ち物は鉄球だけ。お金は0。町の宝箱に少しのお金と回復薬（宝箱は装備ではないので「初期アイテム」ではない）。
- まず町のまわりのスライムを鉄球で倒してお金と素材を集め、武器屋で剣か弓か杖を買うか、鍛冶屋で作る。

## 7. 作り方

- 品物・お店・作り方・敵の種類・ボスの数値は `scripts/rules/` に、先にテストを書いて作る（`ItemCatalog`・`Shop`・`Recipes`・`Buffs`・`EnemyKind`・`BossKind`）。
- 地図は `tools/area_maps/gen.py` を作り直す。拾いものは品物の id で書く。
- 数値はすべて【提案】の仮の値。
